01 / PROJECT OVERVIEW

About The Project

A hands-on DevOps implementation focused on automated application deployment.

⚙

CI/CD Automation

Jenkins automates source-code checkout, validation, Docker image building, deployment and smoke testing.

Containerization

Web Deployment
